## 📖 เกี่ยวกับโปรเจกต์ (About This Portal)
เว็บแอปพลิเคชันทบทวนเนื้อหาและคลังข้อสอบเสมือนจริงเจาะลึก **แนวข้อ 7 (แบบจำลองเครื่องสูบน้ำ และทฤษฎีบทบัคกิ้งแฮม พาย / Buckingham $\Pi$ Theorem)** ออกแบบมาให้อ่านทบทวนและฝึกทำโจทย์ได้ทุกที่ผ่านโทรศัพท์มือถือ แท็บเล็ต หรือคอมพิวเตอร์

### 🌟 ฟีเจอร์เด่น:
- **ทบทวนมโนทัศน์ (Core Principles):** สรุปการเลือกตัวแปรซ้ำ $(D, \rho, \mu)$ และการแก้กลุ่มไร้มิติ $\Pi_1, \Pi_2$ ภายใน 1 นาที
- **โจทย์ข้อ 7 ต้นฉบับ:** เฉลยวิธีทำ 4 สเต็ปตามแบบฉบับอาจารย์ผู้สอน
- **ข้อสอบเสมือน 3 ระดับความยาก (3-Tier Practice Problems):**
  - **ระดับ 1 (Warm-up):** ดัดแปลงตัวเลข สเกล 1:5 ของไหลคือน้ำทั้งคู่
  - **ระดับ 2 (Midterm Standard):** โจทย์ทิศทางย้อนกลับ ทำนาย Prototype จากข้อมูลทดสอบใน Lab
  - **ระดับ 3 (Mastery):** ดัดแปลงของไหล (น้ำมันทดสอบสู่ Prototype น้ำ) ค่า $\rho, \mu$ ไม่ตัดกัน
- **ระบบทดสอบคำตอบโต้ตอบได้ (Interactive Self-Assessment):** ช่องกรอกคำตอบเพื่อตรวจผลทันที พร้อมปุ่มเปิด/ซ่อนวิธีทำ 4 สเต็ป
- **การตรวจสอบความถูกต้องด้วย Reynolds Number ($Re$):** พิสูจน์ความคล้ายคลึงทางพลศาสตร์ $Re_m = Re_p$
- **จุดที่ข้อสอบชอบดักคะแนน (Common Exam Traps):** สรุปจุดตัดคะแนนยอดฮิต
