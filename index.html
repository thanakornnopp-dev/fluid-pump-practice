1. สรุปมโนทัศน์ & สูตรลัดใน 1 นาที

แก่นของโจทย์เครื่องสูบน้ำแบบหมุนเหวี่ยงตามทฤษฎีบทบัคกิ้งแฮม พาย (Buckingham $\Pi$ Theorem)

ฟังก์ชันตั้งต้นและการเลือกตัวแปรซ้ำ

ความดันที่เพิ่มขึ้นของเครื่องสูบน้ำ $\Delta P$ ขึ้นอยู่กับอัตราการไหล $Q$, ขนาดเส้นผ่านศูนย์กลางใบพัด $D$, และคุณสมบัติของไหล ($\rho, \mu$):

$$\Delta P = f(Q,\ D,\ \rho,\ \mu)$$

นับตัวแปร: $k = 5$ ตัว ($\Delta P, Q, D, \rho, \mu$), มิติพื้นฐาน: $r = 3$ ($M, L, T$) ดังนั้นจะได้กลุ่มไร้มิติ $\Pi = 5 - 3 = 2$ กลุ่ม โดยเลือกตัวแปรซ้ำคือ $(D, \rho, \mu)$

$$\Pi_1 = \frac{D^2 \rho\,\Delta P}{\mu^2} \qquad\qquad \Pi_2 = \frac{\rho\,Q}{D\,\mu}$$

สูตรสำเร็จในการจับคู่ Model และ Prototype

เมื่อตั้ง $\Pi_m = \Pi_p$ จะได้สูตรสำเร็จที่ใช้ทำนายผลได้ทันที:

  • กรณีของไหลชนิดเดียวกัน (น้ำทั้งคู่): $\rho$ และ $\mu$ ตัดทอนกันหมด $$Q_m = \left(\frac{D_m}{D_p}\right) Q_p \qquad\qquad \Delta P_m = \left(\frac{D_p}{D_m}\right)^2 \Delta P_p$$
  • กรณีของไหลต่างชนิดกัน: ต้องแทนค่าความหนาแน่นและความหนืดครบทุกตัว $$Q_m = Q_p \left(\frac{D_m}{D_p}\right)\left(\frac{\rho_p}{\rho_m}\right)\left(\frac{\mu_m}{\mu_p}\right) \qquad\qquad \Delta P_m = \Delta P_p \left(\frac{D_p}{D_m}\right)^2 \left(\frac{\rho_p}{\rho_m}\right)\left(\frac{\mu_m}{\mu_p}\right)^2$$
ถัดไป →2. ข้อ 7 ต้นฉบับอาจารย์

2. ข้อ 7 ต้นฉบับ: แบบจำลองเครื่องสูบน้ำ

ตัวอย่างข้อสอบบทที่ 4 ข้อ 7 แสดงวิธีทำ 4 สเต็ปมาตรฐานของอาจารย์

โจทย์

ตัวอย่างบทที่ 4 ข้อ 7 การทดสอบ Prototype ของเครื่องสูบน้ำที่จะสูบน้ำด้วยอัตรา $1.5\ \text{m}^3/\text{s}$ โดยส่วนที่เป็นใบพัดมีเส้นผ่านศูนย์กลางเท่ากับ $40\ \text{cm}$ และความดันเพิ่มขึ้น $400\ \text{kPa}$ โดยที่แบบจำลองมีใบพัดมีเส้นผ่านศูนย์กลางเท่ากับ $8\ \text{cm}$ จงหาอัตราการไหลและความดันที่เพิ่มขึ้นในแบบจำลอง กำหนดให้ของไหลที่ใช้ในแบบจำลองและ Prototype คือน้ำ
พารามิเตอร์แบบจำลอง (Model)Prototype
$D$$D_m = 8\ \text{cm} = 0.08\ \text{m}$$D_p = 40\ \text{cm} = 0.40\ \text{m}$
$Q$$Q_m = ?$$Q_p = 1.5\ \text{m}^3/\text{s}$
$\Delta P$$\Delta P_m = ?$$\Delta P_p = 400\ \text{kPa}$
ของไหลน้ำ ($\rho_m = \rho_p$)น้ำ ($\mu_m = \mu_p$)

ขั้นตอนการแก้โจทย์

  1. อัตราการไหล $Q_m$ จาก $\Pi_2$

    $$\frac{Q_m}{D_m} = \frac{Q_p}{D_p} \implies Q_m = \left(\frac{D_m}{D_p}\right) Q_p = \left(\frac{0.08}{0.40}\right)(1.5) = \mathbf{0.30\ \text{m}^3/\text{s}}$$

  2. ความดันเพิ่มขึ้น $\Delta P_m$ จาก $\Pi_1$

    $$D_m^2\,\Delta P_m = D_p^2\,\Delta P_p \implies \Delta P_m = \left(\frac{D_p}{D_m}\right)^2 \Delta P_p = \left(\frac{0.40}{0.08}\right)^2 (400\ \text{kPa}) = 25 \times 400 = \mathbf{10,000\ \text{kPa}}$$

อัตราการไหลในแบบจำลอง

$$Q_m = 0.30\ \text{m}^3/\text{s}$$

ความดันที่เพิ่มขึ้นในแบบจำลอง

$$\Delta P_m = 10,000\ \text{kPa} = 10\ \text{MPa}$$

3. ข้อสอบเสมือน 1: สเกล 1:5 ของไหลคือน้ำทั้งคู่ (ระดับ Warm-up)

ฝึกความแม่นยำในการแทนค่าและทิศทางของอัตราส่วนขนาด

โจทย์

แบบฝึกหัดที่ 1 การทดสอบเครื่องสูบน้ำ Prototype ซึ่งออกแบบมาให้สูบน้ำด้วยอัตราการไหล $2.0\ \text{m}^3/\text{s}$ เส้นผ่านศูนย์กลางใบพัด $50\ \text{cm}$ และสร้างความดันเพิ่มขึ้น $500\ \text{kPa}$ วิศวกรต้องการสร้างแบบจำลอง (Model) ที่มีขนาดเส้นผ่านศูนย์กลางใบพัด $10\ \text{cm}$ โดยใช้น้ำในการทดสอบเช่นเดียวกัน จงหาอัตราการไหล ($Q_m$) และความดันที่เพิ่มขึ้น ($\Delta P_m$) ในแบบจำลอง
ทดสอบคำนวณด้วยตนเอง

  1. อัตราส่วนขนาดเส้นผ่านศูนย์กลาง

    $$\frac{D_m}{D_p} = \frac{10\ \text{cm}}{50\ \text{cm}} = \frac{0.10\ \text{m}}{0.50\ \text{m}} = \frac{1}{5} = 0.20$$

  2. หา $Q_m$ จาก $\Pi_2 = \dfrac{\rho Q}{D \mu}$

    $$Q_m = \left(\frac{D_m}{D_p}\right) Q_p = (0.20)(2.0\ \text{m}^3/\text{s}) = \mathbf{0.40\ \text{m}^3/\text{s}}$$

  3. หา $\Delta P_m$ จาก $\Pi_1 = \dfrac{D^2 \rho \Delta P}{\mu^2}$

    $$\Delta P_m = \left(\frac{D_p}{D_m}\right)^2 \Delta P_p = (5)^2 \times (500\ \text{kPa}) = 25 \times 500 = \mathbf{12,500\ \text{kPa}} = \mathbf{12.50\ \text{MPa}}$$

อัตราการไหล $Q_m$

$$0.40\ \text{m}^3/\text{s}$$

ความดัน $\Delta P_m$

$$12,500\ \text{kPa} = 12.5\ \text{MPa}$$

4. ข้อสอบเสมือน 2: ทิศทางย้อนกลับ Lab $\rightarrow$ Prototype (ระดับ Midterm)

โจทย์สไตล์ข้อสอบมิดเทอมที่วัดผลการทดสอบในห้องแลป แล้วให้ทำนายพฤติกรรมของเครื่องสูบน้ำจริง

โจทย์

แบบฝึกหัดที่ 2 ในห้องปฏิบัติการ วิศวกรทำการทดสอบแบบจำลองเครื่องสูบน้ำขนาดเล็กที่มีเส้นผ่านศูนย์กลางใบพัด $D_m = 12\ \text{cm}$ โดยใช้น้ำในการทดสอบ วัดอัตราการไหลได้ $Q_m = 0.45\ \text{m}^3/\text{s}$ และความดันเพิ่มขึ้น $\Delta P_m = 6,400\ \text{kPa}$ จงทำนายอัตราการไหล ($Q_p$) และความดันที่เพิ่มขึ้น ($\Delta P_p$) ของเครื่องสูบน้ำ Prototype ของจริงที่มีขนาดเส้นผ่านศูนย์กลางใบพัด $D_p = 48\ \text{cm}$ เมื่อใช้งานกับน้ำเช่นเดียวกัน
ทดสอบคำนวณด้วยตนเอง

  1. อัตราส่วนขยายขนาด (Scale Ratio)

    $$\lambda = \frac{D_p}{D_m} = \frac{48\ \text{cm}}{12\ \text{cm}} = \frac{0.48\ \text{m}}{0.12\ \text{m}} = 4.0$$

  2. ทำนายอัตราการไหล $Q_p$

    $$Q_p = \left(\frac{D_p}{D_m}\right) Q_m = (4.0)(0.45\ \text{m}^3/\text{s}) = \mathbf{1.80\ \text{m}^3/\text{s}}$$

  3. ทำนายความดันเพิ่มขึ้น $\Delta P_p$

    $$\Delta P_p = \left(\frac{D_m}{D_p}\right)^2 \Delta P_m = \left(\frac{1}{4.0}\right)^2 (6,400\ \text{kPa}) = \frac{6,400}{16} = \mathbf{400\ \text{kPa}}$$

อัตราการไหล $Q_p$

$$1.80\ \text{m}^3/\text{s}$$

ความดัน $\Delta P_p$

$$400\ \text{kPa}$$

5. ข้อสอบเสมือน 3: ของไหลต่างชนิด น้ำมัน $\rightarrow$ น้ำ (ระดับ Mastery)

ระดับท้าทายสูงสุด: เมื่อของไหลของแบบจำลองไม่ใช่ของไหลชนิดเดียวกับ Prototype

โจทย์

แบบฝึกหัดที่ 3 การทดสอบแบบจำลองเครื่องสูบน้ำขนาดใบพัด $D_m = 6\ \text{cm}$ โดยใช้สารหล่อลื่นพิเศษ ($\rho_m = 800\ \text{kg/m}^3, \mu_m = 1.20 \times 10^{-3}\ \text{Pa}\cdot\text{s}$) เพื่อจำลองเครื่องสูบน้ำจริง (Prototype) สูบน้ำ ($\rho_p = 1,000\ \text{kg/m}^3, \mu_p = 1.00 \times 10^{-3}\ \text{Pa}\cdot\text{s}$) ขนาด $D_p = 30\ \text{cm}$ ทำงานที่ $Q_p = 1.25\ \text{m}^3/\text{s}$ และ $\Delta P_p = 360\ \text{kPa}$ จงหาอัตราการไหล ($Q_m$) และความดันที่เพิ่มขึ้น ($\Delta P_m$) ในแบบจำลอง
ทดสอบคำนวณด้วยตนเอง

  1. หา $Q_m$ (ค่า $\rho$ และ $\mu$ ไม่ตัดกัน)

    $$Q_m = Q_p \left(\frac{D_m}{D_p}\right) \left(\frac{\rho_p}{\rho_m}\right) \left(\frac{\mu_m}{\mu_p}\right)$$ $$Q_m = (1.25) \times \left(\frac{0.06}{0.30}\right) \times \left(\frac{1,000}{800}\right) \times \left(\frac{1.20 \times 10^{-3}}{1.00 \times 10^{-3}}\right) = \mathbf{0.375\ \text{m}^3/\text{s}}$$

  2. หา $\Delta P_m$

    $$\Delta P_m = \Delta P_p \left(\frac{D_p}{D_m}\right)^2 \left(\frac{\rho_p}{\rho_m}\right) \left(\frac{\mu_m}{\mu_p}\right)^2$$ $$\Delta P_m = (360) \times (5)^2 \times (1.25) \times (1.20)^2 = 360 \times 25 \times 1.25 \times 1.44 = \mathbf{16,200\ \text{kPa}} = \mathbf{16.20\ \text{MPa}}$$

อัตราการไหล $Q_m$

$$0.375\ \text{m}^3/\text{s}$$

ความดัน $\Delta P_m$

$$16,200\ \text{kPa} = 16.20\ \text{MPa}$$

6. สรุปจุดดักคะแนนสอบ & เคล็ดลับจาก Inspector

3 สิ่งที่นักศึกษาวิศวกรรมมักทำพลาดในห้องสอบ และสูตรโกงตรวจคำตอบใน 10 วินาที

3 ข้อผิดพลาดยอดฮิต

  • 1. ทิศทางของอัตราส่วนขนาด $D$: สำหรับ $Q$ อัตราส่วนคือ $(D_m/D_p)^1$ (แบบจำลองเล็กกว่า $Q$ ต้องน้อยกว่า) แต่สำหรับ $\Delta P$ อัตราส่วนคือ $(D_p/D_m)^2$ (แบบจำลองเล็กกว่า ความดันกลับพุ่งสูงขึ้นเป็นกำลังสอง) ให้ตั้งสมการและย้ายข้างเสมอ อย่าเดาในใจ
  • 2. ที่มาของมิติ $P$ และ $\mu$: ในกระดาษคำตอบ ขั้นตอนที่ 2 ต้องแสดงที่มา $P = F/A = ML^{-1}T^{-2}$ และ $\tau = \mu(du/dy) \implies \mu = ML^{-1}T^{-1}$ เสมอ เพราะอาจารย์มีช่องให้คะแนนเฉพาะตรงนี้
  • 3. ตัวแปรซ้ำต้องเป็นชุดเดิม: ทุกกลุ่ม $\Pi$ ต้องใช้ $(D, \rho, \mu)$ ชุดเดียวกัน ห้ามสลับตัวแปรซ้ำไปมาระหว่างข้อ

สูตรโกงตรวจคำตอบด้วย Reynolds Number ($Re$)

เนื่องจาก $\Pi_2 \propto Re$ ดังนั้นเมื่อทำเสร็จ ให้ลองตรวจดูว่า $Re_m = Re_p$ หรือไม่:

$$Re = \frac{4 \rho Q}{\pi D \mu}$$

ถ้าค่า $Re$ ทั้งสองฝั่งเท่ากัน แสดงว่าตัวเลขที่คุณคำนวณมานั้นถูกต้องแม่นยำ 100% แน่นอน!
