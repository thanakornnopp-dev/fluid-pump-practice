1. สรุปมโนทัศน์ & สูตรลัดใน 1 นาที

แก่นของโจทย์เครื่องสูบน้ำแบบหมุนเหวี่ยงตามทฤษฎีบทบัคกิ้งแฮม พาย (Buckingham $\Pi$ Theorem)

ฟังก์ชันตั้งต้นและการเลือกตัวแปรซ้ำ

ความดันที่เพิ่มขึ้นของเครื่องสูบน้ำ $\Delta P$ ขึ้นอยู่กับอัตราการไหล $Q$, ขนาดเส้นผ่านศูนย์กลางใบพัด $D$, และคุณสมบัติของไหล ($ ho, \mu$):

$$\Delta P = f(Q,\ D,\ ho,\ \mu)$$

นับตัวแปร: $k = 5$ ตัว ($\Delta P, Q, D, ho, \mu$), มิติพื้นฐาน: $r = 3$ ($M, L, T$) ดังนั้นจะได้กลุ่มไร้มิติ $\Pi = 5 - 3 = 2$ กลุ่ม

$$\Pi_1 = rac{D^2 ho\,\Delta P}{\mu^2} \qquad\qquad \Pi_2 = rac{ ho\,Q}{D\,\mu}$$

สูตรสำเร็จในการจับคู่ Model และ Prototype

เมื่อตั้ง $\Pi_m = \Pi_p$ จะได้สูตรสำเร็จที่ใช้ทำนายผลได้ทันที:

  • กรณีของไหลชนิดเดียวกัน (น้ำทั้งคู่): $ ho$ และ $\mu$ ตัดทอนกันหมด $$Q_m = \left( rac{D_m}{D_p} ight) Q_p \qquad\qquad \Delta P_m = \left( rac{D_p}{D_m} ight)^2 \Delta P_p$$
  • กรณีของไหลต่างชนิดกัน: ต้องแทนค่าความหนาแน่นและความหนืดครบทุกตัว $$Q_m = Q_p \left( rac{D_m}{D_p} ight)\left( rac{ ho_p}{ ho_m} ight)\left( rac{\mu_m}{\mu_p} ight) \qquad\qquad \Delta P_m = \Delta P_p \left( rac{D_p}{D_m} ight)^2 \left( rac{ ho_p}{ ho_m} ight)\left( rac{\mu_m}{\mu_p} ight)^2$$
ถัดไป →2. ข้อ 7 ต้นฉบับอาจารย์

2. ข้อ 7 ต้นฉบับ: แบบจำลองเครื่องสูบน้ำ

ตัวอย่างข้อสอบบทที่ 4 ข้อ 7 แสดงวิธีทำ 4 สเต็ปมาตรฐานของอาจารย์

โจทย์

ตัวอย่างบทที่ 4 ข้อ 7 การทดสอบ Prototype ของเครื่องสูบน้ำที่จะสูบน้ำด้วยอัตรา $1.5\ ext{m}^3/ ext{s}$ โดยส่วนที่เป็นใบพัดมีเส้นผ่านศูนย์กลางเท่ากับ $40\ ext{cm}$ และความดันเพิ่มขึ้น $400\ ext{kPa}$ โดยที่แบบจำลองมีใบพัดมีเส้นผ่านศูนย์กลางเท่ากับ $8\ ext{cm}$ จงหาอัตราการไหลและความดันที่เพิ่มขึ้นในแบบจำลอง กำหนดให้ของไหลที่ใช้ในแบบจำลองและ Prototype คือน้ำ
พารามิเตอร์แบบจำลอง (Model)Prototype
$D$$D_m = 8\ ext{cm} = 0.08\ ext{m}$$D_p = 40\ ext{cm} = 0.40\ ext{m}$
$Q$$Q_m = ?$$Q_p = 1.5\ ext{m}^3/ ext{s}$
$\Delta P$$\Delta P_m = ?$$\Delta P_p = 400\ ext{kPa}$
ของไหลน้ำ ($ ho_m = ho_p$)น้ำ ($\mu_m = \mu_p$)

ขั้นตอนการแก้โจทย์

  1. อัตราการไหล $Q_m$ จาก $\Pi_2$

    $$ rac{Q_m}{D_m} = rac{Q_p}{D_p} \implies Q_m = \left( rac{D_m}{D_p} ight) Q_p = \left( rac{0.08}{0.40} ight)(1.5) = \mathbf{0.30\ ext{m}^3/ ext{s}}$$

  2. ความดันเพิ่มขึ้น $\Delta P_m$ จาก $\Pi_1$

    $$D_m^2\,\Delta P_m = D_p^2\,\Delta P_p \implies \Delta P_m = \left( rac{D_p}{D_m} ight)^2 \Delta P_p = \left( rac{0.40}{0.08} ight)^2 (400\ ext{kPa}) = 25 imes 400 = \mathbf{10,000\ ext{kPa}}$$

อัตราการไหลในแบบจำลอง

$$Q_m = 0.30\ ext{m}^3/ ext{s}$$

ความดันที่เพิ่มขึ้นในแบบจำลอง

$$\Delta P_m = 10,000\ ext{kPa} = 10\ ext{MPa}$$

3. ข้อสอบเสมือน 1: สเกล 1:5 ของไหลคือน้ำทั้งคู่ (ระดับ Warm-up)

ฝึกความแม่นยำในการแทนค่าและทิศทางของอัตราส่วนขนาด

โจทย์

แบบฝึกหัดที่ 1 การทดสอบเครื่องสูบน้ำ Prototype ซึ่งออกแบบมาให้สูบน้ำด้วยอัตราการไหล $2.0\ ext{m}^3/ ext{s}$ เส้นผ่านศูนย์กลางใบพัด $50\ ext{cm}$ และสร้างความดันเพิ่มขึ้น $500\ ext{kPa}$ วิศวกรต้องการสร้างแบบจำลอง (Model) ที่มีขนาดเส้นผ่านศูนย์กลางใบพัด $10\ ext{cm}$ โดยใช้น้ำในการทดสอบเช่นเดียวกัน จงหาอัตราการไหล ($Q_m$) และความดันที่เพิ่มขึ้น ($\Delta P_m$) ในแบบจำลอง
ทดสอบคำนวณด้วยตนเอง

  1. อัตราส่วนขนาดเส้นผ่านศูนย์กลาง

    $$ rac{D_m}{D_p} = rac{10\ ext{cm}}{50\ ext{cm}} = rac{0.10\ ext{m}}{0.50\ ext{m}} = rac{1}{5} = 0.20$$

  2. หา $Q_m$ จาก $\Pi_2 = \dfrac{ ho Q}{D \mu}$

    $$Q_m = \left( rac{D_m}{D_p} ight) Q_p = (0.20)(2.0\ ext{m}^3/ ext{s}) = \mathbf{0.40\ ext{m}^3/ ext{s}}$$

  3. หา $\Delta P_m$ จาก $\Pi_1 = \dfrac{D^2 ho \Delta P}{\mu^2}$

    $$\Delta P_m = \left( rac{D_p}{D_m} ight)^2 \Delta P_p = (5)^2 imes (500\ ext{kPa}) = 25 imes 500 = \mathbf{12,500\ ext{kPa}} = \mathbf{12.50\ ext{MPa}}$$

อัตราการไหล $Q_m$

$$0.40\ ext{m}^3/ ext{s}$$

ความดัน $\Delta P_m$

$$12,500\ ext{kPa} = 12.5\ ext{MPa}$$

4. ข้อสอบเสมือน 2: ทิศทางย้อนกลับ Lab $ ightarrow$ Prototype (ระดับ Midterm)

โจทย์สไตล์ข้อสอบมิดเทอมที่วัดผลการทดสอบในห้องแลป แล้วให้ทำนายพฤติกรรมของเครื่องสูบน้ำจริง

โจทย์

แบบฝึกหัดที่ 2 ในห้องปฏิบัติการ วิศวกรทำการทดสอบแบบจำลองเครื่องสูบน้ำขนาดเล็กที่มีเส้นผ่านศูนย์กลางใบพัด $D_m = 12\ ext{cm}$ โดยใช้น้ำในการทดสอบ วัดอัตราการไหลได้ $Q_m = 0.45\ ext{m}^3/ ext{s}$ และความดันเพิ่มขึ้น $\Delta P_m = 6,400\ ext{kPa}$ จงทำนายอัตราการไหล ($Q_p$) และความดันที่เพิ่มขึ้น ($\Delta P_p$) ของเครื่องสูบน้ำ Prototype ของจริงที่มีขนาดเส้นผ่านศูนย์กลางใบพัด $D_p = 48\ ext{cm}$ เมื่อใช้งานกับน้ำเช่นเดียวกัน
ทดสอบคำนวณด้วยตนเอง

  1. อัตราส่วนขยายขนาด (Scale Ratio)

    $$\lambda = rac{D_p}{D_m} = rac{48\ ext{cm}}{12\ ext{cm}} = rac{0.48\ ext{m}}{0.12\ ext{m}} = 4.0$$

  2. ทำนายอัตราการไหล $Q_p$

    $$Q_p = \left( rac{D_p}{D_m} ight) Q_m = (4.0)(0.45\ ext{m}^3/ ext{s}) = \mathbf{1.80\ ext{m}^3/ ext{s}}$$

  3. ทำนายความดันเพิ่มขึ้น $\Delta P_p$

    $$\Delta P_p = \left( rac{D_m}{D_p} ight)^2 \Delta P_m = \left( rac{1}{4.0} ight)^2 (6,400\ ext{kPa}) = rac{6,400}{16} = \mathbf{400\ ext{kPa}}$$

อัตราการไหล $Q_p$

$$1.80\ ext{m}^3/ ext{s}$$

ความดัน $\Delta P_p$

$$400\ ext{kPa}$$

5. ข้อสอบเสมือน 3: ของไหลต่างชนิด น้ำมัน $ ightarrow$ น้ำ (ระดับ Mastery)

ระดับท้าทายสูงสุด: เมื่อของไหลของแบบจำลองไม่ใช่ของไหลชนิดเดียวกับ Prototype

โจทย์

แบบฝึกหัดที่ 3 การทดสอบแบบจำลองเครื่องสูบน้ำขนาดใบพัด $D_m = 6\ ext{cm}$ โดยใช้สารหล่อลื่นพิเศษ ($ ho_m = 800\ ext{kg/m}^3, \mu_m = 1.20 imes 10^{-3}\ ext{Pa}\cdot ext{s}$) เพื่อจำลองเครื่องสูบน้ำจริง (Prototype) สูบน้ำ ($ ho_p = 1,000\ ext{kg/m}^3, \mu_p = 1.00 imes 10^{-3}\ ext{Pa}\cdot ext{s}$) ขนาด $D_p = 30\ ext{cm}$ ทำงานที่ $Q_p = 1.25\ ext{m}^3/ ext{s}$ และ $\Delta P_p = 360\ ext{kPa}$ จงหาอัตราการไหล ($Q_m$) และความดันที่เพิ่มขึ้น ($\Delta P_m$) ในแบบจำลอง
ทดสอบคำนวณด้วยตนเอง

  1. หา $Q_m$ (ค่า $ ho$ และ $\mu$ ไม่ตัดกัน)

    $$Q_m = Q_p \left( rac{D_m}{D_p} ight) \left( rac{ ho_p}{ ho_m} ight) \left( rac{\mu_m}{\mu_p} ight)$$ $$Q_m = (1.25) imes \left( rac{0.06}{0.30} ight) imes \left( rac{1,000}{800} ight) imes \left( rac{1.20 imes 10^{-3}}{1.00 imes 10^{-3}} ight) = \mathbf{0.375\ ext{m}^3/ ext{s}}$$

  2. หา $\Delta P_m$

    $$\Delta P_m = \Delta P_p \left( rac{D_p}{D_m} ight)^2 \left( rac{ ho_p}{ ho_m} ight) \left( rac{\mu_m}{\mu_p} ight)^2$$ $$\Delta P_m = (360) imes (5)^2 imes (1.25) imes (1.20)^2 = 360 imes 25 imes 1.25 imes 1.44 = \mathbf{16,200\ ext{kPa}} = \mathbf{16.20\ ext{MPa}}$$

อัตราการไหล $Q_m$

$$0.375\ ext{m}^3/ ext{s}$$

ความดัน $\Delta P_m$

$$16,200\ ext{kPa} = 16.20\ ext{MPa}$$

6. สรุปจุดดักคะแนนสอบ & เคล็ดลับจาก Inspector

3 สิ่งที่นักศึกษาวิศวกรรมมักทำพลาดในห้องสอบ และสูตรโกงตรวจคำตอบใน 10 วินาที

3 ข้อผิดพลาดยอดฮิต

  • 1. ทิศทางของอัตราส่วนขนาด $D$: สำหรับ $Q$ อัตราส่วนคือ $(D_m/D_p)^1$ (แบบจำลองเล็กกว่า $Q$ ต้องน้อยกว่า) แต่สำหรับ $\Delta P$ อัตราส่วนคือ $(D_p/D_m)^2$ (แบบจำลองเล็กกว่า ความดันกลับพุ่งสูงขึ้นเป็นกำลังสอง) ให้ตั้งสมการและย้ายข้างเสมอ อย่าเดาในใจ
  • 2. ที่มาของมิติ $P$ และ $\mu$: ในกระดาษคำตอบ ขั้นตอนที่ 2 ต้องแสดงที่มา $P = F/A = ML^{-1}T^{-2}$ และ $ au = \mu(du/dy) \implies \mu = ML^{-1}T^{-1}$ เสมอ เพราะอาจารย์มีช่องให้คะแนนเฉพาะตรงนี้
  • 3. ตัวแปรซ้ำต้องเป็นชุดเดิม: ทุกกลุ่ม $\Pi$ ต้องใช้ $(D, ho, \mu)$ ชุดเดียวกัน ห้ามสลับตัวแปรซ้ำไปมาระหว่างข้อ

สูตรโกงตรวจคำตอบด้วย Reynolds Number ($Re$)

เนื่องจาก $\Pi_2 \propto Re$ ดังนั้นเมื่อทำเสร็จ ให้ลองตรวจดูว่า $Re_m = Re_p$ หรือไม่:

$$Re = rac{4 ho Q}{\pi D \mu}$$

ถ้าค่า $Re$ ทั้งสองฝั่งเท่ากัน แสดงว่าตัวเลขที่คุณคำนวณมานั้นถูกต้องแม่นยำ 100% แน่นอน!
